# LaUltimaMilpa
Prototipo de supervivencia día/noche en una milpa maya de Yucatán.

## Requisitos
**Godot 4.7.2 stable** (versión estándar, no .NET): <https://godotengine.org/download>

## Cómo abrir el proyecto
1. Clona el repositorio y cambia a la rama de trabajo.
2. Abre Godot → **Project Manager** → **Import**.
3. Selecciona el `project.godot` de la raíz del repositorio.
4. Pulsa **F5** para ejecutar.
